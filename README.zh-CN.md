# siyuan-general-outline

为思源笔记当前活动文档提供右侧标题标记。默认只有细短横线，鼠标移入时向左展开标题目录，移出后自动收起。

![原创插件图标](icon.png)

## 安装

1. 找到思源当前工作空间目录。在思源「设置 → 关于」中可查看工作空间位置。
2. 将 `package.zip` 解压到 `<工作空间>/data/plugins/siyuan-general-outline/`。该目录下应直接看到 `plugin.json`、`index.js`、`index.css` 和 `icon.png`，不要再嵌套一层同名目录。
3. 重启思源，在「设置 → 集市 → 插件 → 已下载」中启用 `siyuan-general-outline`。首次使用插件时，按思源自身提示开启插件支持。
4. 打开包含 H1–H6 标题的文档，即可看到编辑区右侧标记。

也可以直接将本项目目录的运行文件复制到上述插件目录。插件运行无需 Node.js、npm、API Key 或联网下载依赖。安装方式依据[思源官方插件示例](https://github.com/siyuan-note/plugin-sample)。

## 使用

- 每个文内标题对应一个标记；H1–H6 用不同长度的短线区分，当前阅读位置高亮。
- 悬停后显示序号、标题级别和缩进；点击文字或标记定位。长标题省略显示，停留时可查看原文提示。
- 导航最多占当前编辑区可视高度的 **2/3**；标题过多时，鼠标放在目录上滚动。
- 从思源内核读取当前文档的完整大纲，已折叠或尚未渲染到 DOM 的标题也会收录。接口失败时只显示已加载标题并标明状态，可点击「刷新」重试。
- 编辑、新增、删除、移动标题后自动刷新；切换标签页和分屏时跟随当前活动编辑区，不合并其他文档的标题。
- 已加载的标题直接滚动定位；未加载或被折叠的标题通过思源原生块导航加载定位。
- 对折叠区域内的标题，会使用思源原生聚焦视图展示目标，可通过面包屑返回全文；不会为了跳转改写笔记的折叠属性。
- 默认不将文件名作为标题节点；正文中的重复标题按块 ID 分别保留。
- Tab 可以聚焦标记，↑ / ↓ 选择，Home / End 到首尾，Enter / 空格跳转，Esc 收起。
- 点击顶部原创图标可开关导航；右键图标选择「标题导航设置」。设置可调整最大标题级别、序号、行距及右侧边距。命令面板也提供切换、刷新和聚焦命令，可在思源快捷键设置中自行绑定。
- 跟随思源主题颜色；禁用插件会移除导航、事件监听和观察器。

适用于桌面客户端、独立文档窗口和桌面浏览器前端。最低声明版本为思源 3.3.0；实测版本记录见下方。不声明移动端及发布服务支持。
